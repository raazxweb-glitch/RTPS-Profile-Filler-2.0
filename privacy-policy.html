Privacy Policy – RTPS Profile Filler 2.0

Last updated: August 14, 2026

Developer: RAAZ X WEB

Extension: RTPS Profile Filler 2.0

1. Purpose

RTPS Profile Filler 2.0 is a productivity extension that helps users save profile information and automatically fill supported Bihar RTPS application forms for Income, Residence and Caste certificates.

2. Information handled

The extension may handle information that the user voluntarily enters or saves in a profile, such as applicant names, family names, address details and other information required for supported RTPS forms.

3. How information is used

This information is used only to provide the extension's profile management, save and autofill functionality on supported RTPS application pages.

4. Storage

Saved profile information is stored using the browser extension's storage functionality. The extension does not sell user information.

5. Data sharing

The extension does not sell or share saved profile information with third parties for advertising, creditworthiness, lending, or unrelated purposes.

6. User control

Users can manage their saved profiles using the extension's available profile controls, including changing or deleting profiles and using export/import features where available.

7. Security and user responsibility

Users should review all automatically filled information before submitting any government application. Users should avoid saving information they do not want stored by the extension.

8. Government affiliation

This extension is an independent productivity tool. It is not affiliated with, sponsored by, or officially endorsed by the Government of Bihar or Bihar RTPS.

9. Changes

This privacy policy may be updated if the extension's functionality or data practices change. The latest version will be published on this page.
